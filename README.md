# Gopper VPN: ядро с AmneziaWG (libcore-awg.aar)

Собранное ядро sing-box/libneko с поддержкой AmneziaWG для приложения
«Гоппер VPN». Ветка существует для хранения и доставки ядра: код
приложения с awg-интеграцией в публичный репозиторий не выкладывается,
это ядро — единственное, что хранится на GitHub.

## Как применить

Скопировать файл в проект:

```
copy /y libcore-awg.aar <репозиторий>\app\libs\libcore.aar
```

и собрать `assembleOssRelease` на ветке `awg`.

## Проверка подлинности

MD5 (первые 8 знаков): `1af8f902`

Перед сборкой сверять MD5: awg = `1af8f902`, noawg = `05edf527`
(`app/libs/` не отслеживается git'ом, файл переживает переключения
веток как есть).
